# Ling's Lore 3: o Restaurante Contra-Ataca

Nessa continuação do Ling's Lore, Ling sai em uma nova jornada inesquecível.

Após derrotar Tonald Drump e seu exército na invasão do restaurante 變態的食物, agora em destroços, Ling se encontra tomado pela perda e descobre um alvo para sua angústia e sede de vingança: o amigo de Drump, Nenjamin Betanyahu, o big Yahu. Com seu objetivo firmado, ele sai em busca de uma resposta para seu sofrimento.
